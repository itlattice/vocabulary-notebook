# Vocabulary Notebook

一个VSCode翻译插件，帮助你在编码之余轻松学习外语单词。

## 功能特性

### 📚 学习单词
- 选中任意英文单词，右键选择"学习单词"
- 自动获取单词的音标、释义（按词性分类）、例句及翻译
- 在侧边面板展示详细内容
- 一键收藏到本地单词本

### 📝 翻译文件
- 支持翻译整个 `.txt` 或 `.md` 文件
- 右键菜单选择"翻译文件"即可
- 翻译结果在新标签页显示

### 📖 单词本管理
- 左侧活动栏展示所有已保存的单词
- 单词按字母顺序(a-z)排列
- 显示单词及其主要释义
- 点击单词查看详细内容
- 支持手动添加/删除单词
- 数据本地存储，随时查阅

## 使用方法

### 1. 配置LLM API
首次使用需要配置API：

1. 按 `Ctrl + ,` 打开设置
2. 搜索 `vocabulary notebook`
3. 配置以下项：
   - **LLM API Base URL**: 你的API地址（OpenAI格式）
   - **LLM API Key**: 你的API密钥
   - **LLM Model**: 模型名称（如 `gpt-3.5-turbo`）
   - **Storage Path**: 单词本存储路径（可选，默认使用扩展目录）

### 2. 学习单词
1. 在编辑器中选中一个单词
2. 右键选择"学习单词"
3. 查看右侧面板的详细释义
4. 点击"记录到单词本"保存

### 3. 查看单词本
1. 点击左侧活动栏的"单词本"图标
2. 浏览所有已保存的单词
3. 点击单词查看详细内容

## 配置项说明

- `vocabularyNotebook.llm.baseUrl`: LLM API地址（默认：`https://api.openai.com/v1`）
- `vocabularyNotebook.llm.apiKey`: API密钥（必填）
- `vocabularyNotebook.llm.model`: 使用的模型（默认：`gpt-3.5-turbo`）
- `vocabularyNotebook.storage.path`: 单词本存储位置（可选）

## 系统要求

- VSCode 1.137.0 或更高版本
- 有效的LLM API密钥（OpenAI或兼容格式）

## 已知问题

- 翻译质量取决于所配置的LLM模型
- 需要稳定的网络连接访问API
