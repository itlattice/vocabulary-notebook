一个功能强大的VSCode翻译插件，帮助你在编码之余轻松学习外语单词。支持智能翻译、单词学习、关键词提取，让学习无缝融入编程工作流。

## ✨ 功能特性

### 📚 学习单词

- 🔍 **快速查词**：选中任意英文单词，右键选择"学习单词"
- 📖 **全面释义**：自动获取音标、释义（按词性分类）、例句及翻译
- 💡 **直观展示**：在侧边面板展示详细内容，排版清晰易读
- ⭐ **一键收藏**：点击"记录到单词本"永久保存
- 🔤 **智能去重**：自动处理大小写，避免重复收录（如 Hello 和 hello）

### 🔄 智能翻译器

- 🎯 **侧栏集成**：左侧边栏翻译视图，随时翻译不打断工作流
- 🌐 **三语互译**：支持中文、英文、日语三语互译
- 🤖 **自动识别**源语言：
  - 中文 → 英文
  - 英文/日语 → 中文
  - 支持手动选择目标语言
- 📝 **灵活输入**：支持单词、短语、段落翻译
- 📋 **便捷操作**：一键复制翻译结果
- 🔁 **反向翻译**：点击即可将结果反向翻译，验证准确性

### 🤖 智能单词收录

- ⚡ **单词自动收录**：翻译单个英文单词时自动添加到单词本（可选）
- 🎯 **关键词提取**：翻译长文本时自动提取3-5个关键词并收录（可选）
- 🔠 **智能规范化**：所有单词自动转为小写，专有名词和缩写除外

### 📝 翻译文件

- 📄 **批量翻译**：支持翻译整个 `.txt` 或 `.md` 文件
- 🖱️ **右键即用**：在文件资源管理器右键选择"翻译文件"
- 📑 **结果展示**：翻译结果在新标签页显示，方便对比查看

### 📖 单词本管理

- 📂 **集中管理**：左侧活动栏展示所有已保存的单词
- 🔤 **字母排序**：单词按字母顺序(a-z)排列，快速查找
- 👀 **预览释义**：列表中显示单词及其主要释义
- 🔍 **查看详情**：点击单词查看完整内容（音标、释义、例句）
- ✏️ **灵活编辑**：支持手动添加/删除单词
- 💾 **本地存储**：数据保存在本地SQLite数据库，安全可靠

## 🚀 快速开始

### 1️⃣ 安装插件

在VSCode扩展市场搜索 `Vocabulary Notebook` 并安装。

### 2️⃣ 配置LLM API

首次使用需要配置API：

1. 按 `Ctrl + ,`（Mac: `Cmd + ,`）打开设置
2. 搜索 `vocabulary notebook`
3. 配置以下必填项：
   - **LLM API Base URL**: 你的API地址（支持OpenAI及兼容格式）
     - 示例：`https://api.openai.com/v1`
   - **LLM API Key**: 你的API密钥（必填）
   - **LLM Model**: 模型名称
     - 推荐：`gpt-4`、`gpt-3.5-turbo`、`claude-3-sonnet` 等
4. 可选配置：
   - **Storage Path**: 单词本存储路径（默认使用扩展目录）
   - **Auto Add Word**: 是否自动收录单个单词（默认：关闭）
   - **Auto Extract Keywords**: 是否自动提取关键词（默认：关闭）

### 3️⃣ 开始使用

配置完成后，点击左侧活动栏的"单词本"图标即可开始使用。

## 📖 使用指南

### 使用翻译器

1. 点击左侧活动栏的 **📚 单词本** 图标
2. 在 **"翻译"** 视图中输入要翻译的内容
3. 选择目标语言（或使用 **"自动"** 识别）
4. 点击 **"翻译"** 按钮或按 `Ctrl/Cmd + Enter`
5. 查看翻译结果：
   - 点击 **"复制"** 按钮复制结果
   - 点击 **"反向翻译"** 验证翻译准确性

### 学习单词

1. 在编辑器中选中一个英文单词
2. 右键选择 **"学习单词"**（或使用快捷键）
3. 右侧面板自动显示单词详细信息：
   - 音标
   - 各词性的释义
   - 双语例句
4. 点击 **"记录到单词本"** 保存到本地

### 翻译文件

1. 在文件资源管理器中右键点击 `.txt` 或 `.md` 文件
2. 选择 **"翻译文件"**
3. 在新标签页查看翻译结果

### 管理单词本

1. 点击左侧活动栏的 **📚 单词本** 图标
2. 在 **"我的单词"** 视图浏览所有已保存的单词
3. 点击单词查看完整详情
4. 右键单词可选择 **"删除"**

## ⚙️ 配置项说明

## ⚙️ 配置项说明

### LLM 配置

| 配置项                             | 说明        | 默认值                        | 必填 |
| ---------------------------------- | ----------- | ----------------------------- | ---- |
| `vocabularyNotebook.llm.baseUrl` | LLM API地址 | `https://api.openai.com/v1` | ✅   |
| `vocabularyNotebook.llm.apiKey`  | API密钥     | -                             | ✅   |
| `vocabularyNotebook.llm.model`   | 使用的模型  | `gpt-3.5-turbo`             | ✅   |

### 存储配置

| 配置项                              | 说明           | 默认值   | 必填 |
| ----------------------------------- | -------------- | -------- | ---- |
| `vocabularyNotebook.storage.path` | 单词本存储位置 | 扩展目录 | ❌   |

### 翻译器配置

| 配置项                                                | 说明                               | 默认值    | 必填 |
| ----------------------------------------------------- | ---------------------------------- | --------- | ---- |
| `vocabularyNotebook.translator.autoAddWord`         | 翻译单个单词时自动添加到单词本     | `false` | ❌   |
| `vocabularyNotebook.translator.autoExtractKeywords` | 翻译长文本时自动提取关键词到单词本 | `false` | ❌   |

## 💡 使用技巧

### 提高翻译质量

- 使用更强大的模型（如 GPT-4）可获得更准确的翻译和释义
- 对于专业术语，可以在翻译后使用"反向翻译"验证准确性

### 高效学习单词

- 开启"单词自动收录"功能，翻译时自动建立单词库
- 开启"关键词提取"功能，从文章翻译中自动积累核心词汇
- 定期复习单词本中的单词，巩固记忆

### 文件翻译建议

- 适合翻译README、文档、注释等文本文件
- 对于大型文件，建议分段翻译以获得更好的质量
- 翻译结果可直接保存，方便后续参考

## 🎯 技术特点

- ✅ **本地存储**：使用 SQLite 数据库，数据安全可靠，无需担心隐私泄露

## ❓ 常见问题

### 如何获取API密钥？

- **OpenAI**: 访问 [platform.openai.com](https://platform.openai.com) 注册并创建API密钥
- **其他服务商**: 国内可使用DeepSeek、智谱AI等兼容OpenAI格式的服务

### 翻译结果不准确怎么办？

1. 尝试更换更强大的模型（如 GPT-4）
2. 检查API配置是否正确
3. 使用"反向翻译"功能验证翻译质量

### 单词本数据存储在哪里？

- 默认存储在VSCode扩展的全局存储目录
- 可在设置中自定义存储路径
- 数据为SQLite格式，可随时备份

### 支持哪些语言？

- 目前支持中文、英文、日语三语互译
- 单词学习功能主要针对英文单词
